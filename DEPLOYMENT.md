# Deploy en servidor propio

La guía completa (los 2 repos, los 3 servicios, orden de arranque, todas las variables
de entorno y el checklist de verificación) vive en el repo del backend:

**`Innova-Backend/DEPLOYMENT.md`**

Este repo solo aporta el servicio `frontend` (y `frontend-dev` para desarrollo local) —
ver `deploy/docker-compose.yml` y `.env.example` acá mismo para sus variables.
